# Multimodal-AI-Assistant-Computer-Vision-Speech-to-Speech-Pipeline-with-Local-LLM-Ollama-
Built a fully offline multimodal AI assistant using YOLOv8, OpenCV, Whisper, Ollama (Qwen2.5:0.5B), and text-to-speech. The system detects objects from images, understands spoken questions, and provides context-aware spoken responses, running entirely on a local machine without internet or API costs.
